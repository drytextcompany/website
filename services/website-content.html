Before you call

Questions people ask first.

What does a website page cost?
From Rs 4,800 for a short page like Contact or About, up to about Rs 28,000 for a home or landing page that needs research, several versions and a lot riding on it. You get the exact number before we start.
Do you write for a site I already have?
Yes. Most of this work is rewriting pages that are already live, which is quicker and cheaper than starting again, and usually the honest answer.
Can you design and build it as well?
Yes. The same four people write it, design it and ship it. This website is one of ours, which is the only portfolio piece we can promise is still standing.
What about SEO?
We write for people first and search second, then make sure the page uses the words people actually search for, has one clear job, and has the headings and page information search engines read. No keyword stuffing; it reads badly and stopped working years ago.
How long does a website take?
A single page in a few days. A small site in two to three weeks, depending on how fast decisions come back from your side, which is usually the real timeline.
Who writes the words if I already have a designer?
We do, and we work to their layout. Send the design and we write to the space, or send us the content plan and we write first so the design has something true to hold.

# Stickers and small print — The Dry Text Co.

Fifty-four stickers, a bookmark, a handout for the free line, and a chat pack.
All of it is built from the brand kit in `brand-kit/assets`.

**Every sticker is saved three ways, under the same name**, so you can send or print one on its own:

| Folder | What it is | Use it for |
|---|---|---|
| `singles/<name>.pdf` | **Ready to print.** The page *is* the sticker plus 3 mm bleed: no margin, no crop marks, no caption, artwork running edge to edge. Page two is the cut line, for a shop that asks for one. | Ordering that one sticker |
| `png/<name>.png` | 300 dpi, trimmed, transparent around the shape | Sending to anyone, decks, one-offs |
| `square/<name>.png` | 512 × 512, transparent, centred | WhatsApp packs, Instagram stories |

`contact-sheet.pdf` shows all fifty-four on one page with their names. Start there.

## For the printer

- **Singles:** print the file as it is. It already carries 3 mm of bleed on every edge, and the trim
  is 3 mm inside the page edge. Ignore page two unless you want the cut line.
- **Sheets:** matt white vinyl, kiss-cut on the magenta lines. The magenta is a guide, not ink.
- **Clear vinyl for three:** `strike`, `circle-it` and `tick`. Their middles must stay see-through.
- **Colours:** Paper `#FBFBF9`, Ink `#16161A`, Red `#D2232A`. Match the red to the hex;
  Pantone 186 C is the nearest standard red, so ask for a draw-down before a long run.
- **Fonts** are embedded as proper subsets in all 58 PDFs, so upload portals will accept them.

# Final stickers — the chosen nineteen

The set you picked, at every quality that matters. Same nineteen designs in four formats, all
under the same file name, so `badge-50` is `badge-50` wherever you look.

| Folder | What it is | Use it for |
|---|---|---|
| `print-pdf/` | **Vector. This is the master.** Shapes are shapes, type is type, fonts embedded. Zoom to a billboard and it stays sharp. One page per sticker: the page is the sticker plus 3 mm bleed, nothing else on it. | Anything printed, at any size |
| `png-1200dpi/` | Pictures at 1200 dpi. A 50 mm sticker is 2362 px across. | Big prints, or when a shop insists on an image |
| `png-600dpi/` | Pictures at 600 dpi — twice the usual print standard | Everyday printing, decks, mockups |
| `square-2048/` | 2048 × 2048, transparent, centred | Instagram, presentations, anything on screen |
| `square-512/` | 512 × 512, transparent | WhatsApp sticker packs |

`contact-sheet.pdf` shows all nineteen on one page with their names.

## Why the earlier ones looked soft

They were 300 dpi pictures. Fine on paper, soft the moment you zoom in on a screen. Nothing was
wrong with the artwork: the PDFs were always vector. Now the pictures go up to 1200 dpi, and the
vector file sits next to them.

**Rule of thumb:** if it is going to a printer, send the PDF. Send a PNG only when someone
specifically asks for an image.

## For the printer

- Matt white vinyl. Paper `#FBFBF9`, Ink `#16161A`, Red `#D2232A` — match the red to the hex,
  Pantone 186 C is the nearest standard.
- The PDFs already carry 3 mm of bleed; trim 3 mm inside the page edge. Single page each, no cut-guide page.
- `gujarati` reads "શબ્દો અમારા. વખાણ તમારા." Have someone read it before a long run.
